## Install

- **Mac** (Apple silicon, macOS 13 or later): download the `.dmg`, open it and drag Qalam Studio into Applications. macOS stops it the first time, since it isn't notarized yet: [here's how to open it](https://github.com/ahmedamr-r/qalam-studio/blob/main/docs/install-mac.md).
- You also need [Claude Code](https://code.claude.com/docs/en/quickstart) or Codex signed in with your own account, or an Anthropic API key.
