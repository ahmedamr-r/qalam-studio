## Install

- **Mac** (Apple silicon, macOS 13 or later): download the `.dmg`, open it and drag Qalam Studio into Applications. If macOS won't open it the first time, [here's how to open it](https://github.com/ahmedamr-r/qalam-studio/blob/main/docs/install-mac.md).
- **Windows** (x64): download the `.exe` and run it. If SmartScreen stops it, click **More info ▸ Run anyway**.
